# Требования проекта

Этот раздел фиксирует требования, которые закрывает текущая реализация.

## Функциональные требования

- Хранение логинов и паролей.
- Хранение произвольных текстовых секретов.
- Хранение данных банковских карт.
- Хранение binary-файлов через MinIO.
- Хранение OTP secrets и генерация TOTP-кодов на клиенте.
- CLI-клиент.
- TUI-клиент.
- gRPC binary protocol.
- OpenAPI описание HTTP projection контракта.
- Функциональные и интеграционные тесты.

## Безопасность

- Сервер не получает plaintext пользовательских секретов.
- Vault key создается на клиенте.
- Vault key шифруется мастер-паролем.
- Access token используется только для авторизации gRPC-запросов.
- Binary chunks шифруются до отправки в `BlobService`.
- OTP secret не логируется и не отображается в открытом виде в detail view.

## Инфраструктура

- PostgreSQL хранит пользователей, vault items и blob metadata.
- MinIO хранит encrypted binary chunks.
- Docker Compose поднимает все локальные зависимости.
- CI проверяет форматирование, vet, тесты и сборку.
- Coverage gate не ниже 70%.
- Документация публикуется через Read the Docs.

## Ограничения MVP

- Offline cache не реализован.
- Refresh token flow не реализован.
- Интерактивное разрешение конфликтов не реализовано.
- Clipboard для TUI не используется.
- Runtime transport остается gRPC.
